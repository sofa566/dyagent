# 008-line 變更計畫（LINE 雙向通道與人工接手機制）

## 目標

讓 dyagent 可作為 LINE 官方帳號後端，支援：

1. 使用者透過 LINE 傳送訊息到系統。
2. 系統以指定 Agent 產生回覆並回傳到 LINE。
3. 系統操作員在新的「LINE 對話中心」介面查看與主動回覆。
4. 支援 `bot/human` 模式切換，實現人工接手。

---

## 核心原則

1. 通道層與對話核心解耦：LINE 僅做事件轉接，不複製聊天引擎。
2. 會話可追蹤：所有入站/出站訊息落地，具稽核能力。
3. 權限最小化：只有具管理權限者可人工發送訊息。
4. 相容既有資料流：訊息同步進既有 `Conversation/Message`，與原聊天頁共通。

---

## 分階段

### 階段 1：後端通道接入

- 新增 LINE webhook 端點與簽章驗證。
- 新增 LINE session/message 資料模型與 migration。
- 建立入站訊息到 Agent 回覆的最小流程。

### 階段 2：人工接手 API

- 新增 LINE session 列表與訊息查詢 API。
- 新增 `mode=bot|human` 切換 API。
- 新增操作員 push 訊息 API。

### 階段 3：前端操作台

- 新增 `line-console.html`。
- 支援會話清單、訊息檢視、模式切換、Agent 指派、人工送訊。
- 舊 `agent-rag-config` 轉為退場導引頁（已完成）。

### 階段 4：驗證與文件

- 新增 LINE 通道整合測試。
- 更新規格/計畫/任務檔與部署說明。
